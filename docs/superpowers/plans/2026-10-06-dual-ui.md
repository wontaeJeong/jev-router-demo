# Dual UI Router Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Provide a presentation-ready Textual TUI and local web dashboard with inspectable original HTTP bodies and abbreviated previews.

**Architecture:** Keep Python adapters and measurement semantics. A shared session yields per-router completion events; both frontends consume the same serialized snapshot and inspector helpers. FastAPI serves packaged static assets and one independent session per WebSocket.

**Tech Stack:** Python 3.12+, httpx, Pydantic, Rich, Textual, FastAPI, Uvicorn, vanilla HTML/CSS/JavaScript, pytest.

**Spec:** `docs/superpowers/specs/2026-10-06-dual-ui-design.md`

## Global Constraints

- Python 3.12+; preserve existing dotenv and router contracts.
- Requests and stored originals must never be abbreviated.
- Strings exceeding 480 characters retain the first 320 and last 120 characters.
- No Node build or CDN; static files ship inside the Python package.
- `uv run jev-router-demo` launches TUI; `--web` binds 127.0.0.1:8000 by default.
- Sessions are independent; no database, execution history, or downstream execution.
- Existing unavailable/partial usage and success-only average latency semantics remain.
- Main checkout remains on main; all changes happen in feat/demo-dual-ui worktree.

## File responsibilities

- `models.py`, `routers/base.py`: typed HTTP exchange and transport capture.
- `inspection.py`: pure abbreviation, inspector serialization and original exports.
- `session.py`: incremental comparison events and session metrics.
- `tui.py`, `tui.tcss`: Textual interaction, layout and editor screen.
- `web.py`, `static/index.html`, `static/app.js`, `static/style.css`: local server, protocol and browser UI.
- `main.py`: entrypoint selection; keep legacy piped CLI for existing automation.
- `tests/test_inspection.py`, `test_session.py`, `test_tui.py`, `test_web.py`: meaningful feature contracts.
- `README.md`, `pyproject.toml`, `uv.lock`, `.gitignore`: usage, dependencies, packaged assets, generated export exclusion.
